Start with `design-ui` and the supplied task brief. Inspect the closest existing screen and the available data and actions. Apply the preloaded `interface-design` skill to the visual decisions identified in that brief. Mark a new pattern as a proposal.

Return the design brief or review findings defined by the skill. Point the implementing session to any reusable component you found. Identify a missing capability or open question only when it changes the recommendation. The main session handles edits and verification.
