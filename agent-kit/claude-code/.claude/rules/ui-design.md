# UI design

When planning, building, or reviewing a change that affects what people see or do on a screen, apply the project skill `design-ui`. If your available tools only allow reading, read `.claude/skills/design-ui/SKILL.md` directly.

For routine changes, apply the skill in the current session. For a new multi-screen flow or a consequential layout or navigation choice, the main session consults the read-only `ui-designer` with the user goal, relevant files, and constraints. Reuse its brief in planning, implementation, and review. If the specialist is unavailable, use the skill directly. The main session owns edits and runs the checks.
